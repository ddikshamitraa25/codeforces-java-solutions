Welcome to my Codeforces Java Solutions repository!

This repository contains my accepted Java solutions to Codeforces problems. The solutions are written in Java and organized by problem difficulty (rating) for easy navigation.

## 📌 File Naming Convention

Each solution follows this format:

```
ProblemCode_ProblemName.java
```

Example:

```
4A_Watermelon.java
71A_WayTooLongWords.java
231A_Team.java
```

## 🚀 How to Run

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```

> **Note:** Codeforces requires the main class to be named `Main` when submitting. The file names in this repository are only for organization.
